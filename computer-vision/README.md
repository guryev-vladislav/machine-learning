# Computer Vision

This directory contains practical computer vision projects focused on image classification, semantic segmentation, and video analysis. The projects cover both custom deep learning architectures and production-oriented workflows built with established computer vision libraries.

The implementations include dataset preparation, model training, evaluation metrics, result visualization, and inference pipelines.

## Projects

- [Concrete Crack Detection](concrete_crack_detection/) - a PyTorch pipeline for detecting concrete cracks with U-Net segmentation and CNN classification. It includes training reports, metrics, and visual comparisons.
- [YOLO Crack Detection](yolo-crack-detection/) - an Ultralytics YOLO classification pipeline for identifying cracks in images and video frames, with configurable training, inference, and experiment logging.
- [CNN MNIST Segmentation](cnn-mnist-segmentation/) - a custom convolutional neural network for isolating and classifying handwritten digits.
- [U-Net MNIST Segmentation](unet-mnist-segmentation/) - an encoder-decoder segmentation pipeline for separating handwritten digits from their backgrounds.
